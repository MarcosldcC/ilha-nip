# Bit (antigo "Ilha NIP")

Copiloto flutuante para Windows (Electron). O código é **um só para qualquer pessoa**: tudo que é pessoal (nome, cargo, time, frentes, regras, prazos, termos) vem do **perfil** (`src/profile.js`, `DATA.profile`, Config > Seu perfil). Nunca coloque nomes, empresas ou siglas de alguém no código; use o perfil.
O JEV (TypeSafe) classifica e prioriza (perguntas montadas do perfil: `qMensagem`/`qDemanda`). O Claude Code do próprio usuário (`claude -p`, limite do plano) separa as demandas e escreve. Não usa chave da Anthropic.
Instalador/app = "Bit" (shell v2). Pasta de dados: `%APPDATA%\Bit` em instalação nova; quem já tinha `%APPDATA%\Ilha NIP\ilha-data.json` continua nela (`shell/boot.js`). Cada pessoa tem os próprios dados no próprio PC; nada de dados pessoais em `src/` (nem nos MOCKs: use nomes genéricos como Ana/Bruno).

## Conceitos
- **Bit**: o robozinho (rosto SVG em `renderer/app.js` → `FACE_SVG`; humores via `data-mood` no `#island`: idle, working, done, listening, transcribing, error, sleep). Olhos seguem o mouse (main envia `eyes`).
- **Perfil** (`src/profile.js`): `normalize`, `migrate` (instalações antigas com sessão "Copiloto NIP" ganham `LEGADO_NIP` uma vez; sessões viram "Copiloto Bit"), `contexto`/`contextoCurto` para prompts, `vocab` para o Whisper. Prompts em `src/prompts.js` são funções do perfil (`systemCopiloto(p)`, `systemGeral`, `systemReuniao`, `systemTexto`+`tarefaTexto`, `systemAssist`). Na 1ª abertura sem nome no perfil, o Bit abre a Config.
- **Sessões**: várias conversas em paralelo (`DATA.sessions`), cada uma com `kind` (`nip` = Copiloto Bit, pipeline JEV + Claude; o id interno continua `nip`; `geral` = assistente com WebSearch/WebFetch) e `model` (haiku/sonnet/opus).
- **Ferramentas** (`src/tools.js` no main + `renderer/tools.js`): Arquivos (soltar no Bit; imagens via canvas, PDF via `renderer/vendor` pdf.js + pdf-lib, zip via Compress-Archive, descompactar via tar.exe do Windows, Lixeira via shell.trashItem), Notas, Cofre (safeStorage, limpa clipboard em 30s), Reunião ao vivo (mic + loopback do PC em PCM 16k; `feed()` em tools.js corta nas pausas da fala, 1,8–9 s, e descarta silêncio; `whisper-server` fica aberto com o modelo carregado (`voice.serverTranscribe`; ditado também usa). Carrega sozinho (`voice.warm`) ao abrir a Reunião, no microfone/Ctrl+Alt+V e ~4 min antes de reunião da agenda com link; `voice.hold` segura durante a gravação; descarrega após 10 min sem uso, ou nunca com `settings.voiceKeep` ("sempre carregada", carrega 8 s depois de abrir), com o texto anterior como contexto e filtro de alucinações tipo "Obrigado."; resumo pelo Claude; tarefas vão pro Copiloto), Música (SMTC do Windows via PowerShell `-EncodedCommand` + tocador local).
- **UI (v2, "claro e limpo")**: o bloco final de `renderer/style.css` ("v2 · DESIGN") manda: tokens `--win/--surface/--surface-2/--line/--ink/--muted/--accent` e textos `--t-blue/--t-amber/...` com tema claro (padrão) e escuro em `html[data-theme]` (`settings.theme` = claro/escuro/auto, `applyTheme()` em app.js). Cores antigas foram tokenizadas (`rgba(var(--fg),a)`, `rgba(0,0,0,calc(a*var(--bk)))`). Superfícies lisas, sem degradê/brilho; ícones de linha em `window.IC` (nada de emoji). Navegação = barra lateral fina à esquerda (`.nav`, 60px; `.panel{margin-left:60px}`), ícones com `data-tip` (dica à direita); ferramentas são atalhos diretos `data-tab="t:<ferramenta>"` (`go('t:notas')`); Ciclo fica dentro de Demandas (`#cicloBox`); Config é a engrenagem no topo. Janela tem `MARGIN` de 10px em volta da ilha para a sombra.
- **Modo soltar**: `setMode('drop')` abre uma ilha compacta para soltar arquivos. No Windows um PowerShell leve (`DRAG_PS` em main.js) avisa quando o botão do mouse é segurado e manda `F` quando o cursor vira o de arrastar ARQUIVO (cursor OLE de copiar/mover, diferente dos cursores padrão); só abre sozinho se começou no Explorer/Área de Trabalho (`fileDragFromExplorer`). Arrastar janela, aba, app ou texto não abre. De outros apps, o arquivo abre o modo soltar ao passar por cima do Bit (dragenter com `Files`). Configs `dragDetect` e `glassNative` (acrylic do Windows 11, experimental).
- **Sessões do Claude Code no PC** (`src/cc.js`): lê `~/.claude/projects/**/*.jsonl` só para leitura (título via `ai-title`, último pedido via `last-prompt`, status working/waiting/idle pelo mtime + `stop_reason`). Aparecem nas Sessões; "Abrir no terminal" roda `claude --resume <id>` no `cwd`. Dá para responder pela Ilha: `cc:send` roda `claude -p --resume <id> --permission-mode <plan|acceptEdits|auto|bypassPermissions>` no `cwd` da sessão (runClaude com `rawArgs`/`cwd`), com Parar (taskkill). Chats do claude.ai não ficam no PC (só um link para claude.ai/recents).
- **Arquivos**: resultados têm Copiar (arquivo na área de transferência via `Set-Clipboard -LiteralPath`), Enviar para… (escolhe pasta) e Compartilhar (Outlook clássico com anexo; senão copia o arquivo e abre e-mail/WhatsApp/Teams para colar).
- **Arquivos em lote** (`renderer/tools.js` → `renderBatch`/`runBatch`): receita Converter → Comprimir → Nome (`{nome}` `{n}` `{data}`) → Salvar em (mesma pasta / "Convertidos" / escolher) → Depois (zip, copiar, abrir pasta, originais pra Lixeira). Receita salva em `meta.batch` (sem o "Lixeira"). PNG comprimido usa UPNG.js (paleta de 256/128 cores, estilo TinyPNG; vendor em `renderer/vendor`). Renomear: um arquivo (lápis) ou os originais com o padrão (`files:rename`).
- **Conversões grátis** (`src/convert.js`, IPC `conv:*`): vídeo/áudio/GIF pelo FFmpeg (baixa sozinho na 1ª vez para `dados/tools/ffmpeg`, build BtbN ou gyan), HEIC via WIC do Windows, Word/Excel/PowerPoint → PDF e PDF → Word pelo Office instalado (COM) ou LibreOffice (`soffice --headless`), texto/MD/HTML/CSV → PDF com `printToPDF` (janela oculta). Planilhas (xlsx/xls/ods/csv/json, juntar em abas) via SheetJS no renderer; CSV com `;` lê número brasileiro (8,5) e sai com `;` + BOM. SVG vira imagem pelo `<img>`. PDF: separar páginas, girar 90° e extrair páginas (`1-3, 5`) com pdf-lib.
- **Lote por tipo**: `kindOf()` em `renderer/tools.js` agrupa (img, heic, video, audio, pdf, sheet, doc, slides, text, other) e a etapa Converter mostra uma linha por tipo; `REC.conv` é um objeto por tipo. Erros por arquivo não param o lote.
- **Agenda e Lembretes** (`src/extras.js` + `renderer/extras.js`, aba `t:agenda`): lê links ICS publicados (novo Outlook/web: "Publicar calendário"; Google: "endereço secreto iCal") com `net.fetch` a cada 10 min; recorrência, exceções e fusos via `src/vendor/ical.js` (ical.js 1.5.0). Link fica criptografado (safeStorage). Acha link de Teams/Meet/Zoom; aviso N min antes (`settings.agendaAlert`), chip na pílula, botões Entrar / Gravar (`window.meetStartWith`) / Nota. Lembretes em português ("amanhã às 10h", "em 20 min", "sexta 15h30", "dia 28") interpretados no renderer (`parseWhen`), disparados pelo main (`DATA.reminders`). Repetição: `repeat = {k: dia|util|semana|mes|cada, days?, every?}`; o renderer entende "todo dia", "dias úteis", "toda segunda e quarta", "todo dia 10", "a cada 2 horas" (`parseRepeat`/`parseRem`), e o main (`makeRem`/`nextOcc`) acerta a 1ª vez. Ao tocar, a série cria um aviso avulso (`from` = id da série, com Feito/Adiar) e pula para a próxima vez. Botão 🔁 em cada lembrete (`rem:repeat`); o roteador do assistente manda `repetir`/`dias`/`a_cada_min`.
- **Histórico do copiar** (`t:clip`, Ctrl+Alt+H): main lê o clipboard a cada 700 ms, guarda até 200 textos (+ fixados) criptografados em `ilha-clips.bin`; ignora o que vem do Cofre (`clipIgnore`) e conteúdo marcado `ExcludeClipboardContentFromMonitorProcessing`. Ctrl+Alt+H lembra a janela da frente e Enter cola nela.
- **Reescrever texto** (`t:texto`, Ctrl+Alt+X): campos opcionais Para quem / Para quê / Onde vai (e-mail, WhatsApp, Teams, LinkedIn, documento) / Tom / Tamanho (salvos em `meta.txOpts`), "Só corrigir os erros", e ajustes rápidos (mais curto/formal/leve/outra versão). Um PowerShell residente (`KEYS_PS`) espera soltar as teclas, manda Ctrl+C na janela da frente e devolve o HWND; o main restaura o clipboard. A tarefa vem de `tarefaTexto(opts)` + `systemTexto(p)` (texto puro como prompt) rodam no Claude (`settings.textModel`, padrão haiku). "Colar no lugar" foca a janela original e manda Ctrl+V.
- **Início = assistente** (`assistSend` em `renderer/app.js`, IPC `assist:run` em main.js): o card "Fala com o Bit" (e a voz fora do chat) entende o pedido. Atalhos locais instantâneos: "me lembra… às 15h" (`window.remParse`) e "anota: …". O resto vai para o roteador Haiku (`systemAssist(p)` em prompts.js, contexto = agora + agenda + lembretes + demandas) que devolve `{acoes, resposta}`: lembrete, nota, demanda (`addDemands`), foco, gravar, abrir, copiloto (manda pra sessão do Copiloto), geral. Cada item criado tem "desfazer" (`assist:undo`). Modos do Copiloto (bom dia, decisão…) vão direto pro Copiloto. Card "Seu dia" (`renderToday` em renderer/extras.js) mostra reuniões e lembretes de hoje + top 3 demandas, atualizando sozinho.
- **Claude ou ChatGPT** (`settings.ai` = `claude` | `chatgpt`): escolhido nos Primeiros passos (`aiStep`/`pickAi` em app.js) ou em Config > Inteligência. Tudo passa por `claude()` em main.js, que chama `runClaude` ou `runCodex` (engine.js: `codex exec --json --ephemeral --ignore-user-config --sandbox read-only`, system prompt via `-c model_instructions_file=`, prompt pelo stdin, `-c web_search="live"` só quando há WebSearch, senão `"disabled"`). Os níveis continuam `haiku/sonnet/opus` por dentro; no ChatGPT viram Rápido/Equilibrado/Forte (`MODEL_LABEL` é um Proxy) = `model_reasoning_effort` low/medium/high, com nome de modelo opcional por nível em `settings.codexModels` (vazio = padrão da conta). Login = `codex login` (conta do ChatGPT); status via `~/.codex/auth.json` ou `codex login status`. Instalação: `irm https://chatgpt.com/codex/install.ps1 | iex` (vai para `%LOCALAPPDATA%\Programs\OpenAI\Codex\bin`). O Codex não faz streaming de texto (a mensagem chega inteira). Sessões do Claude Code no PC (`cc.js`) continuam só Claude.
- **JEV → Haiku**: `jevCall` marca o JEV como fora (`JEVST`) quando falta crédito/chave (60 min), limite (10 min) ou erro (5 min) e aí `addDemands` usa a prioridade do Haiku (extração do Claude). `settings.engine = 'haiku'` força só Haiku. Selo "JEV + Claude"/"Haiku" no card (`engine:status`). Teste: `ILHA_JEV_DOWN=1` com `ILHA_MOCK=1`.
- **Janela**: posição = âncora (centro do topo) em `meta.anchor`; arrasta pelo rostinho (`#barFace` → `win:dragStart`/`win:moveEnd`, o main segue o cursor); redimensiona aberto pela alça no canto (`#resizeGrip`, `meta.expSize`, mín. 640×440; duplo clique na alça volta ao padrão). Modo bolinha (`meta.bubble`, modo `bubble` 60×60): ao recolher fica só o rostinho; botão `#bubbleBtn` no topo, `#barMin` na pílula, item na bandeja. Reunião em andamento pode ser encerrada à mão (× no chip, botão Encerrar no Seu dia/Agenda; ids em `meta.agDone`).
- **Demanda aberta (detalhes)**: clicar no título abre o painel com campos editáveis Título/Quem/Prazo, **O que é** (`descricao`, preenchida pelo Claude na extração), Pedido original (`origem` = trecho), Próximo passo e **Observações** (`obs`). Salva no `change` via `demands:update`. `descricao`/`obs` entram no `openDemandsSummary` (contexto da IA).
- **Só demandas minhas**: a extração pede `responsavel` (quem FAZ) e `addDemands` descarta o que não for do usuário (`PROFILE.isMine`: "Eu"/vazio ou nome parecido com `profile.nome` — prefixo de 4 letras ou similaridade ≥ 0,66), avisando no feed. Cobrar alguém vira demanda minha ("Cobrar Ana sobre X"). No renderer, `isMineD(d)` faz a mesma checagem: contagens, top 3 e grupos de prioridade só mostram as minhas; as de outros (campo "Quem faz" editável) ficam no grupo recolhido "De outras pessoas (só acompanhar)".
- **Configurações** (`.cfg2` em index.html): submenu `#cfgNav` (vira faixa horizontal com `@container cfg` < 700px) + seções `.cfg-sec` com scrollspy; 1ª seção "Primeiros passos" (`renderSetup()` + IPC `setup:status`: perfil, Claude instalado/logado, voz, agenda, JEV) com botão de ação por item. Dicas da barra lateral = `.tipf` flutuante (JS), texto em `data-tip`.
- **Prazos importantes** (Demandas > `#cicloBox`) e regras vêm do perfil.
- **Cofre**: itens `kind` = `chave` (token/API) ou `conta` (nome, usuário, site, senha); gerador de senha no formulário.
- Evite nomes de classe genéricos que colidem: `.tools` é o contêiner das ferramentas (a barra de "Copiar" das mensagens é `.mtools`), `.mic` é o botão de microfone.
- Classes CSS de trilha da reunião são `t-mic`/`t-sys` (não use `.mic`, que é o botão de microfone).
- Mensagem do usuário vai **pura** como prompt; histórico e contexto vão no system prompt (o Haiku erra fatos quando a pergunta vem embrulhada).

## Estrutura
- `shell/boot.js`: inicializador que vai dentro do `.exe`. **Não muda** sem gerar um instalador novo. Ao abrir, baixa a versão mais nova de `src/` deste repositório (privado, com token do GitHub salvo pelo app) e a carrega.
- `src/`: o app em si (main, engine, prompts, renderer). **Tudo aqui se atualiza sozinho** no PC do usuário.
- `src/manifest.json`: versão e sha256 de cada arquivo de `src/`. O app só atualiza quando a `version` daqui for maior que a instalada.
- `scripts/manifest.js`: gera o manifesto.

## Como publicar uma atualização (sem reinstalar)
1. Edite os arquivos em `src/`.
2. `node --check` nos .js alterados.
3. `node scripts/manifest.js <nova-versão> "o que mudou"` (ex.: 1.2.0). Sempre suba a versão.
4. Commit e push na `main`. Na próxima vez que o app abrir (ou em até 4h, se já estiver aberto), ele baixa e aplica a versão nova.

Atualização sem token só funciona com o repositório **público** (boot.js busca em raw.githubusercontent); privado exige token do GitHub em Config.

## Quando é preciso gerar um instalador novo
Só quando mudar `shell/boot.js`, a versão do Electron ou `package.json`. Nesse caso, suba `SHELL_VERSION` em `shell/boot.js`, coloque `minShell` no manifesto e rode:
`npm install && npm run pack:win` (gera `dist/Bit-win32-x64`).

## Testar localmente
`ILHA_MOCK=1 ILHA_EXPAND=home npx electron .` (respostas simuladas, sem gastar o plano nem o JEV).

## Roadmap combinado (ainda não feito)
- **Ilha no iPhone (PWA)**: central grátis na nuvem (Cloudflare Workers + Durable Object/D1) com relay por WebSocket de saída (PC e iPhone conectam nela; nada de túnel/porta aberta). Dados criptografados ponta a ponta com chave passada por QR no pareamento. Web Push (iOS 16.4+, instalado na Tela de Início). PC ligado = tudo; PC desligado = lembretes tocam pela central (cron), agenda/notas/demandas do último sync, "Fala com o Bit" básico local, pedidos de IA em fila. Sem app nativo (sem Dynamic Island/Live Activity; iPhone 14 comum não tem Dynamic Island). Etapas: (1) central + pareamento + Seu dia/lembretes/notas/demandas; (2) Fala com o Bit/Copiloto + fila; (3) reunião pelo celular, arquivos, música.
- **Alexa**: lembrete falado na hora via Voice Monkey (API de anúncio; plano grátis = 200 chamadas/mês), disparado pela Ilha (e depois pela central, com PC desligado). Lembrete nativo da Alexa criado de fora não é permitido (Reminders API só cria dentro de uma conversa com a skill). Depois da central: skill privada "Ilha" (Alexa-hosted, grátis, modo desenvolvimento) para perguntar a agenda e criar lembrete/demanda por voz.
